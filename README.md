More projects will be added as I continue learning.

- Networking basics: IP addresses, DNS, IPv4, IPv6, and reverse DNS lookup


## Run a Project

Clone the repository:

```bash
git clone https://github.com/Jay-cyberLab/python-networking-basics.git
cd python-networking-basics
```

Open a project folder and run its program:

```bash
cd 01_todo_list
python3 main.py
```

Each project folder includes its own README with instructions and examples.
