# Terminal To-Do List

A beginner Python terminal application for managing tasks.

## Features

- Add tasks
- Show tasks
- Remove a selected task
- Clear all tasks with confirmation
- Save tasks in a text file
- Load saved tasks when the program starts
- Handle a missing task file safely

## Concepts Practiced

- Lists
- Loops
- Functions
- Conditions
- User input
- File handling
- `try` / `except`
- String methods

## Run the Project

```bash
python3 main.py
