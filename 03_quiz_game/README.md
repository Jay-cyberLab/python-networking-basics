# Python and Networking Quiz Game

A terminal quiz game built with Python. It tests basic Python and networking knowledge.

## Features

- Multiple-choice questions
- Input validation for answers A, B, and C
- Score and percentage calculation
- Feedback based on performance
- Questions stored as dictionaries inside a list

## Concepts Practiced

- Dictionaries
- Lists of dictionaries
- Loops
- Functions
- Input validation
- `enumerate()`
- String methods: `.strip()` and `.upper()`
- Arithmetic and formatted output

## Run

```bash
python3 main.py
```
