# Secure Password Generator

A Python terminal application that creates customizable passwords.

## Features

- Choose password length
- Choose whether to include letters, numbers, and symbols
- Validates user input
- Requires at least one character type
- Guarantees one character from each selected type
- Uses Python's `secrets` module for secure random generation

## Concepts Practiced

- Modules and imports
- Functions with parameters
- Lists
- Loops
- Conditions
- String methods
- Input validation
- `secrets` for secure randomness

## Run

```bash
python3 main.py
```

## Example

```text
Enter password length: 12
Include letters? (yes/no): yes
Include numbers? (yes/no): yes
Include symbols? (yes/no): yes

Generated password: k!9Qm2#xL7@p
```

> The password will be different every time you run the program.
